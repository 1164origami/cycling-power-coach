## 📖 Introduction · 简介

**Cycling Power Coach** is an OpenClaw / QClaw Skill that provides scientific, systematic power-based cycling training guidance. It integrates Joe Friel's classic methodology with cutting-edge research from Coggan/Allen (PMC, MMP), Stephen Seiler (polarized training), Dylan Johnson, and peer-reviewed sports science.

**Cycling Power Coach** 是一个 OpenClaw / QClaw Skill，提供科学、系统化的自行车功率训练指导。它融合了 Joe Friel 的经典方法论与 Coggan/Allen（PMC、MMP）、Stephen Seiler（极化训练）、Dylan Johnson 以及同行评审运动科学的前沿研究。

> ⚠️ This is an **OpenClaw / QClaw Skill** — it provides structured knowledge for AI assistants to reference during conversations about cycling power training, FTP, training zones, periodization, and race strategy.

## 📦 Installation · 安装

### For OpenClaw / QClaw

```bash
# Clone or copy this skill into your skills directory
# 克隆或复制此 skill 到你的 skills 目录

# Option A: Git Clone（推荐）
git clone https://github.com/1164origami/cycling-power-coach.git ~/.qclaw/skills/cycling-power-coach

# Option B: Manual Copy（手动复制）
cp -r cycling-power-coach/ ~/.qclaw/skills/

# Option C: For OpenClaw workspace
cp -r cycling-power-coach/ <your-openclaw-workspace>/skills/
```

The AI assistant loads this skill when triggered by power training, FTP, training zones, or race strategy keywords.

当对话涉及功率训练、FTP、训练区间、比赛策略等关键词时，AI 助手会自动加载此技能。
