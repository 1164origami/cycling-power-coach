# 功率数据分析方法

## 核心指标计算

### 标准化功率 (NP)

**定义**：骑行经过可重复性修正后的平均功率，比平均功率更反映真实努力程度和代谢消耗。

**为什么需要NP**：反复爬坡的骑行平均功率可能与平路相同，但实际代谢消耗更大。NP考虑了这一变异性。

**计算方式**（简化理解）：
1. 按时间序列计算30秒滚动平均功率
2. 对滚动平均值取四次方并求时间平均
3. 对结果开四次方得到NP；不足约20分钟的片段应谨慎解释

**示例**：
- 141W平均功率 + 反复爬坡 → NP = 176W
- 141W平均功率 + 平路 → NP = 149W

### 强度因子 (IF)

**公式**：`IF = NP ÷ 当前有效FTP`。若FTP尚未重测或已经过期，IF/TSS只能作为「基于设置FTP」的估算。

**用途**：比较不同训练/比赛的难度，判断训练是否达到目标强度。

**典型IF参考值**：

| 比赛类型 | IF范围 |
|----------|--------|
| Ironman年龄组 | 0.60-0.70 |
| Ironman精英 | 0.70-0.79 |
| 长距离公路赛 | 0.80-0.89 |
| 长距离计时赛 | 0.90-1.04 |
| 短距离计时赛 | 1.05-1.15 |

### 训练压力分数 (TSS)

**公式**：`TSS = IF² × 时长(小时) × 100`

**示例**：
- IF=0.75，骑行2小时 → TSS = 0.75² × 2 × 100 = **112.5**
- IF=1.00，骑行1小时 → TSS = 1² × 1 × 100 = **100**
- IF=0.60，骑行5小时 → TSS = 0.36 × 5 × 100 = **180**

### 变化指数 (VI)

**公式**：`VI = NP ÷ 平均功率`

**解读**：
- **VI = 1.00**：完美节奏（不可能达到的完美稳态）
- **VI ≤ 1.05**：稳态良好（计时赛、铁三的目标）
- **VI > 1.05**：功率波动较大

**重要**：
- VI过高（如1.21）说明反复加减速，浪费糖原并增加酸中毒
- 公路赛/山地赛VI天然较高（比赛本身多变）
- 功率激增（爬坡时保持目标功率而非降功率）也相当于功率飙升

**示例**：
- Ironman选手正确配速：VI = 1.04，跑步段稳定
- Ironman选手VI=1.21：跑步段崩溃（骑run耗能模式被打破）

## 峰值功率曲线

### 什么是峰值功率曲线

功率与时间成反比，各时长最佳功率（P60, P30, P5, P1, P0.1等）构成个人独特的功率曲线。

### 如何解读

- **对比职业铁三运动员 vs Cat III公路车手**：
  - Cat III冲刺功率更高（1210W vs 825W）
  - 但长时功率更低
  - 曲线形状反映项目特异需求

- **训练可以改变曲线形状**
- 峰值功率曲线是**个人独特的指纹**，可用于评估训练效果和项目适应性

## 成绩管理图（PMC）

### 三个核心指标

| 指标 | 全称 | 计算周期 | 含义 |
|------|------|----------|------|
| **CTL** | 长期训练负荷 | 42天滚动平均 | 体能 |
| **ATL** | 短期训练负荷 | 7天滚动平均 | 疲劳 |
| **TSB** | 训练压力平衡 | CTL - ATL | 状态 |

### 解读

- **TSB为正**：近期模型负荷低于长期负荷，不代表必然适合比赛或局部组织已经修复
- **TSB为负**：近期负荷相对较高，需结合近期运动、主观疲劳与疼痛解释
- **CTL快速上升**：训练强度大，注意监控
- **CTL缓慢下降 + TSB上升**：巅峰期目标

### 巅峰期目标

- **最佳状态**：CTL下降约10%，TSB上升到+15~+25
- **不佳状态**：TSB在可接受范围内但CTL下降超过10%

### 实际应用

使用WKO+或TrainingPeaks日历功能：
1. 设计巅峰期每天的TSS
2. 预测并管理比赛当日的TSB
3. 调整单日TSS直到CTL和TSB达到预期

## 效率系数与解耦监测

### 效率系数 (EF)

**公式**：`EF = NP ÷ 平均心率`

- 在**心率Z2稳定骑行**时计算
- EF持续增长说明有氧能力提升
- EF稳定后可以进阶到甜区训练

### 解耦 (Pw:HR)

**计算**：比较训练前后半段EF差值

**公式**：
```
前半段EF = 前半段NP ÷ 前半段平均心率
后半段EF = 后半段NP ÷ 后半段平均心率
解耦 = |后半段EF - 前半段EF| ÷ 前半段EF × 100%
```

**解读**：
- 稳态耐力骑中**<5%**可作为耐力参考，但并非直接测量糖原或脂肪比例
- **>5%**应排查配速变化、停等、风/坡/热、补水与补给；非稳态骑行不得仅凭解耦诊断体能

## 数据分析实操流程

### 分析一次训练/比赛

1. **确认基本信息**：日期、时长、距离、平均功率
2. **计算/确认NP**：对比NP和平均功率，评估功率稳定性
3. **计算IF**：判断训练强度是否达标
4. **计算TSS**：量化本次训练压力
5. **查看VI**：判断节奏控制质量
6. **对比峰值功率曲线**：评估本次表现
7. **查看心率响应**：是否存在滞后或异常

### 判断训练是否有效

| 指标 | 良好 | 需注意 |
|------|------|--------|
| EF增长趋势 | 持续增长 | 停滞或下降 |
| 解耦 | < 5% | > 5% |
| VI（稳态训练） | ≤ 1.05 | > 1.10 |
| CTL趋势 | 稳步上升 | 快速上升/下降 |

## 5%原则

**适用场景**：某些计时测试使用的经验估算；并非任意运动员、任意时长都遵循「时间翻倍功率只降5%」。

**示例**：
- 30分钟TT平均功率 = 250W
- 60分钟TT预计功率 = 250W × 0.95 = 237.5W

**注意**：FTP测试章节有例外，需综合考虑。
