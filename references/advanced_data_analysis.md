# 高级功率数据分析

基于 Hunter Allen & Andrew Coggan《Training and Racing with a Power Meter》(3rd Ed.) 的深度数据分析方法论，补充 Friel 方法论中未涉及的 WKO+/TrainingPeaks 专业分析工具和技术。

## 性能管理图表（PMC）

### 核心指标

| 指标 | 全称 | 时间常数 | 含义 |
|------|------|----------|------|
| CTL | Chronic Training Load | 42天 | 长期训练负荷 = **体能**（fitness） |
| ATL | Acute Training Load | 7天 | 短期训练负荷 = **疲劳**（fatigue） |
| TSB | Training Stress Balance | CTL - ATL | 训练压力平衡 = **形式**（form） |

> Coggan 原始定义：CTL = 42天TSS指数加权移动平均，ATL = 7天TSS指数加权移动平均。与Friel使用相同术语但计算略有差异——Friel直接引用Coggan模型。

### PMC曲线解读

**TSB正负不代表好坏，要看训练阶段：**

| TSB范围 | 状态 | 含义 |
|---------|------|------|
| +10 ~ +25 | 竞技巅峰 | 减量后，疲劳消除但体能保持 |
| -10 ~ +10 | 正常训练 | 体能与疲劳的平衡训练区 |
| -30 ~ -10 | 高负荷训练 | 强化期常见，需控制持续时长 |
| < -30 | 过度训练风险 | 持续超过2周需警惕 |

**关键原则：**
- CTL 持续上升 = 体能累积（但每周增幅不宜超过 5-8 TSS/day）
- TSB ≠ 比赛表现——TSB=+20但CTL很低也骑不出好成绩
- 赛前减量：保持IF但减少时长，CTL允许降10%，TSB升到+15~+25

### PMC实战规划

**年度周期PMC走势（A级赛目标）：**

```
CTL ↑↑↑ 基础期（持续累积）
CTL ↑   强化期（增速放缓，加入高强度）
CTL →/↓ 巅峰期（减量）
TSB 从 -20~-30 逐渐回到 +15~+25
```

**每周TSS增幅规则：**
- 新手：每周+5-8 TSS/day CTL
- 有经验：每周+3-5 TSS/day CTL
- 每第4周减量25-30%（恢复周）

## 均值最大化功率曲线（MMP / Mean Maximal Power）

### 定义

对一次骑行或一段时间内的所有骑行，计算每个持续时长的最高平均功率：

- 5秒最高平均功率 → 冲刺能力
- 1分钟最高平均功率 → 无氧能力
- 5分钟最高平均功率 → VO₂max能力
- 20分钟最高平均功率 × 0.95 → FTP估算
- 60分钟最大持续努力可用于FTP交叉验证，但不自动等于唯一、恒定的「真实FTP」

### MMP曲线解读

**曲线形状反映车手类型：**

| 曲线特征 | 车手类型 | 典型表现 |
|---------|---------|---------|
| 短时高、长时陡降 | 冲刺型 | 高5s/1min，低20min/60min |
| 全段平稳 | 计时赛型/GC型 | FTP高，曲线斜率缓 |
| 短时低、长时相对高 | 耐力型 | 5s/1min偏低但FTP不差 |
| 全段偏高 | 全能型 | 各时长均优秀 |

### MMP应用

1. **训练效果追踪**：对比不同时期的MMP曲线，看哪些时长有提升
2. **比赛策略**：了解自己的MMP，避免在比赛中超出能力范围进攻
3. **FTP验证**：20分钟MMP × 0.95 应接近当前FTP设定值，偏差>5%需调整
4. **弱点识别**：某时长MMP明显低于同级别车手 → 针对训练

### 90天MMP vs 单次MMP

- **单次MMP**：某一次骑行的功率曲线，受当天状态影响大
- **90天MMP**：过去90天所有骑行综合的最佳曲线，更稳定反映能力
- 建议：每4-6周对比90天MMP，观察趋势

## 功率-时长曲线（Power-Duration Curve / PDC）

### 与MMP的关系

PDC = 长期MMP曲线的拟合版本，更平滑，适合跨赛季比较。

### 经典模型：2-parameter critical power model

**P = W' / t + CP**

- **CP (Critical Power)**：多时长功率—时间模型的渐近线、重度与极重强度域的大致分界；并非生理上可以无限维持的功率，且不等同FTP
- **W' (W-prime)**：CP以上的有限能量储备（千焦），即曲线下方的面积

### W' 的实战意义

| W'大小 | 含义 | 典型车手 |
|--------|------|---------|
| 大（>20kJ） | 反复进攻能力强，恢复快 | 古典赛/绕圈赛车手 |
| 小（<12kJ） | 单次长时间阈值能力强，但进攻恢复慢 | 计时赛车手 |

**W'恢复动态：**
- W'消耗后恢复时间约 2-5 分钟（取决于恢复功率与CP的差距）
- 这解释了为什么甜区训练（接近CP）对提高W'利用率有效
- 比赛中"火柴管理"本质是W'管理

### 3-parameter模型（扩展）

**P = W' / (t - t₀) + CP**

- t₀ = 补偿短时MMP偏差的常数
- 3参数模型对<3分钟的MMP拟合更准确
- WKO+ 和 Golden Cheetah 支持两种模型切换

## 标准化功率（NP）深度分析

### 计算步骤

1. 30秒滚动平均原始功率
2. 将每个30秒平均值取4次方
3. 对所有4次方值取平均
4. 对平均值开4次方

**为什么是4次方？** 因为生理学研究表明，血乳酸堆积与功率的4次方近似成正比（Friel书中简化的描述）。Coggan选择4次方是因为它最能反映间歇训练的真实代谢成本。

### NP适用与不适用场景

| 场景 | NP有效？ | 原因 |
|------|---------|------|
| 公路大组赛 | ✅ | 功率变化大，平均功率低估真实强度 |
| 计时赛 | ✅ 但≈平均功率 | 稳态骑行VI≈1.0，NP≈平均功率 |
| 间歇训练 | ✅ | 间歇期间低功率拉低平均值，NP反映真实消耗 |
| 下坡/滑行多 | ⚠️ | 零功率时段可能使NP偏高 |
| 室内ERG训练 | ✅ 但≈平均功率 | 功率稳定，VI≈1.0 |

### 变化指数（VI）详解

| VI范围 | 评价 | 典型场景 |
|--------|------|---------|
| 1.00 | 完美稳态 | ERG模式训练、完美计时赛 |
| 1.00-1.05 | 稳态良好 | 优质计时赛、甜区训练 |
| 1.05-1.15 | 中等变化 | 公路赛、集体训练 |
| 1.15-1.30 | 高度变化 | 绕圈赛、攻防频繁的公路赛 |
| >1.30 | 极度不稳定 | 批量间歇或数据异常 |

> ⚠️ VI异常高（>1.40）可能是功率计故障或数据异常，需检查

## 效率因子（EF）与解耦进阶

### EF趋势分析

**EF = NP / 平均心率**

- 单次数值意义不大，趋势才是关键
- 基础期应每2周在同类型训练（Z2稳定骑行）中对比EF
- EF提升路径：初期快（神经适应+血容量增加），后期慢（需更大训练量）

**EF提升停滞怎么办：**
1. 检查是否有过度训练迹象（RHR升高、HRV下降、食欲差）
2. 考虑增加恢复周
3. 可能需要增加高强度刺激（从纯Z2过渡到甜区）

### 解耦（Pw:HR）的深度解读

**解耦 = |后半段EF - 前半段EF| / 前半段EF × 100%**

| 解耦值 | 评价 | 行动建议 |
|--------|------|---------|
| <3% | 有氧基础极佳 | 可进入下一训练阶段 |
| 3-5% | 有氧基础良好 | 继续当前训练 |
| 5-8% | 有氧基础一般 | 延长基础期，增加Z2时长 |
| 8-12% | 有氧基础不足 | 大幅增加Z2，降低总训练量 |
| >12% | 高解耦（仅稳态可比） | 检查坡度/变速/温度/补水/补给/仪表，再结合症状考虑评估 |

**解耦恶化的常见原因：**
- 热应激（高温下心血管漂移，心率虚高）
- 脱水
- 燃料不足（糖原耗尽，功率下降但心率维持）
- 过度训练

## 训练压力分数（TSS）的高级应用

### TSS计算

**TSS = (NP × 时长(秒) × NP / FTP) / (FTP × 3600) × 100**

简化：**TSS = IF² × 时长(小时) × 100**

### TSS按训练类型分类

| TSS范围 | 训练类型 | 恢复时间 |
|---------|---------|---------|
| <50 | 相对较低的模型训练负荷 | 不自动等于当天完全恢复；仍需关注疼痛和局部疲劳 |
| 50-100 | 中等训练负荷 | 需要结合当日训练历史、睡眠和身体症状评估 |
| 100-150 | 较高训练负荷 | 恢复跨度个体差异大，不应用固定时数放行 |
| 150-200 | 高训练负荷 | 结合睡眠、疼痛、RPE和后续轻运动表现评估 |
| 200-300 | 很高训练负荷 | 没有统一恢复时数，注意长距离后的局部组织反应 |
| >300 | 极高模型负荷 | 不设置统一恢复时间；结合持续症状与医疗风险判断 |

### 每周TSS目标（按级别）

| 级别 | 周TSS | 骑行次数 |
|------|-------|---------|
| 入门 | 100-200 | 3-4 |
| 初级 | 200-300 | 4-5 |
| 中级 | 300-450 | 5-6 |
| 高级 | 450-700 | 6-7 |
| 精英 | 700-1000+ | 7-10+ |

### TSS密度

**TSS密度 = TSS ÷ 时长(h) = 100 × IF²**，其中IF = NP/FTP。这里是整次运动的**归一化负荷密度**，不是实际运动中每一分钟的功率区间分布。

| 整次骑行 IF（示例） | 对应TSS/h | 含义 |
|---:|---:|---|
| 0.50 | 25 | 很轻松，但是否恢复仍需结合症状 |
| 0.60 | 36 | 整体较低强度 |
| 0.75 | 56.25 | 接近传统Z2上沿的稳态例子 |
| 0.90 | 81 | 整体较高负荷 |
| 1.00 | 100 | 约阈值强度的整段等效负荷 |

**不能把60 TSS/h一律称为恢复骑，更不能将60–80 TSS/h直接标为Z2**。短时间高强度间歇与长时间低强度混合可有相似整段IF；旧FTP会影响全部换算。

## 数据分析工作流程

### 赛后/训练后分析清单

1. **整体概览**：TSS、IF、VI、总时长/距离
2. **功率分布**：功率区间时间分布（是否符合训练目标？）
3. **NP vs 平均功率**：VI判断节奏控制
4. **MMP亮点**：本次骑行的最佳功率出现在哪个时长？
5. **心率响应**：功率-心率关系是否正常？有无心血管漂移？
6. **EF和解耦**：如有Z2段，计算EF和解耦
7. **趋势对比**：与同类型训练/比赛比较，是否进步？

### 常见数据异常与排查

| 异常 | 可能原因 | 处理 |
|------|---------|------|
| NP远高于平均功率且VI>1.5 | 功率计信号丢失（补零） | 检查原始数据，剔除零值段 |
| FTP测试中功率突变 | 功率计电池不足 | 充电后重测 |
| 心率与功率不匹配 | 光电心率延迟/不准 | 使用胸带心率 |
| 20分钟测试MMP远低于预期 | 起步太猛后崩了 | 重新测试，匀速策略 |
| 室内外功率存在差异 | 可能涉及功率源、校准、散热、姿势、协议等 | 对齐条件再判断是否需要分开设定训练区间 |

## 耐久性（Durability）分析

### 什么是耐久性

Durability 衡量车手在长时间疲劳积累后仍能维持高功率输出的能力。与 FTP（60分钟峰值）不同，durability 关注的是**功率衰减速率**。

**经典场景（Dylan Johnson 举例）**：
- 车手A：FTP 350W，4小时后60min功率降至 280W（-20%）→ durability 差
- 车手B：FTP 330W，4小时后60min功率维持 313W（-5%）→ durability 好
- 结果：长距离比赛中车手B胜出

### 影响耐久性的因素（系统综述，PMC12881052）

Ismael et al. (2026) 系统综述21项研究，主要发现：

1. **强度比总量更关键**：
   - 高于 Critical Power 的高强度积累，**更少的总功（2.5-15 kJ/kg）就能引发10-20%功率衰减**
   - 低-中等强度即使积累更大总量，功率衰减也较小
   - 结论：kJ 单独作为疲劳指标**不够准确**，必须结合强度

2. **实践意义**：
   - 比赛中高强度进攻越多，后续耐久表现越差
   - 训练计划应针对性模拟比赛强度分布
   - 恢复日/恢复周的质量直接影响耐久性

### 辅助观察疲劳：踏频衰减（Barsumyan et al., 2026, PMC13063868）

Sparks et al. (2026) 发现：**踏频下降是急性疲劳的有效替代指标**。

**方法**：17名训练有素的车手每月完成60分钟@75% FTP稳态骑行（85次观测）

**主要发现**：
- 后半段踏频下降与**心血管漂移（CV Drift）**显著相关（b=0.61, p=0.024）
- 后半段踏频下降与**有氧解耦（Aerobic Decoupling）**显著相关（r=0.38, p=0.001；b=0.58, p=0.007）
- 每多下降1 rpm踏频 ≈ 心血管漂移增加0.61%，解耦增加0.58%

**实践应用**：
- 长距离骑行中监控踏频（而非仅看功率）
- 踏频异常下降 → 提前补给/降低强度
- 训练中可设计「踏频维持」专项练习

### 如何训练耐久性

**核心原则**（Dylan Johnson 推荐）：
1. **大量Z2基础里程**：提升脂肪氧化能力，节省糖原
2. **长时间含强度训练**：3-4小时骑行中穿插高强度段落（模拟比赛）
3. **不要只堆高功率间歇**：FTP高但durability差的选手屡见不鲜
4. **比赛配速模拟**：在疲劳状态下（2-3小时后）做甜区/次阈值段落

### 数据指标

| 指标 | 计算方法 | 目标 |
|------|----------|------|
| **长骑后持续输出比例** | 在可比条件下比较同等时长前后功率，并注明时间/疲劳条件 | 个体纵向追踪为主，不设所有人通用的85%/75%阈值 |
| **踏频衰减** | (前30min平均踏频 - 后30min平均踏频) ÷ 前30min | <5% 良好 |
| **解耦** | 见前文 | <5% 良好 |
| **W'余额** | 实时W'bal ÷ 初始W' | 比赛末 >20% 说明配速好 |

### 补充：踏频下降作为疲劳指标（Barsumyan et al., 2026）

[Source: PMID 41923151, 17名训练有素自行车手，5个月85次配对观测]

- 在75%FTP的60分钟稳态骑行中，后半段踏频下降与心血管漂移和有氧解耦显著相关
- **每下降1rpm踏频 → 心血管漂移增加0.61%**（p=0.024）
- **每下降1rpm踏频 → 有氧解耦增加0.58%**（p=0.007）
- 重复测量相关性：踏频下降↔心血管漂移 r=0.40（p<0.001）；踏频下降↔有氧解耦 r=0.38（p=0.001）
- **实操意义**：踏频监测是一种简单、无创、广泛可用的疲劳追踪方法。在训练中可实时监控踏频衰减，当踏频开始显著下降时，心血管应变可能已影响表现
### 补充：碳水可用性与耐久性的关系（Main et al., 2026）

[Source: PMID 42228164, 9名训练有素女性自行车手，随机交叉设计]

- 低碳水可用性（糖原耗竭+低碳水摄入≤1g/kg）显著降低第一通气阈值功率（133W vs 152W，Δ-19W，p=0.011）
- 总骑行效率在低碳水条件下降低（p=0.003）
- 股外侧肌和股内侧肌的中位功率频率在低碳水条件下升高 → 表明高阈值运动单位募集增加以补偿糖原耗竭的肌纤维
- 3分钟全力测试的末端功率不受碳水可用性影响（CP不受影响，但VT1下降）
- **核心发现**：碳水可用性是中等至大强度过渡区"耐久性"的重要决定因素
### 补充：U23精英自行车手RPP标准值与耐久性量化（Mateo-March et al., 2026）

[Source: PMID 41934371, 90名U23精英自行车手，2025年四大巡回赛数据]

- **新鲜状态MMP标准值**（相对值）：5s 16.0±1.9 W/kg, 30s ~12 W/kg, 1min ~10 W/kg, 5min ~7.5 W/kg, 20min 5.5±0.5 W/kg
- **疲劳后功率下降**：短时程下降幅度大于长时程
  - 5s MMP在60kJ/kg总功后下降53.8%
  - 20min MMP在6kJ/kg超CP功后下降13.6%
- **关键发现**：超CP功（W'>0）的单位能量衰减率高于总功 → 说明高强度消耗对耐久性的损害更严重

## 平台模型与耐久性结果的边界

无近期最大努力时的平台eFTP「滚动下降」只是模型输出，无法代替实测FTP。运动后后半程功率与踏频下降只提示可能的耐久性问题，不具有唯一病因；疼痛、姿势、风、坡度、补水、碳水均可能干扰。IF/TSS依赖输入FTP准确性。不同算法训练负荷不等价。参见 [multisource_coaching.md](multisource_coaching.md)。
