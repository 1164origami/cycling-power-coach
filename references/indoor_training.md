# 室内骑行训练指南

基于 Hunter Allen、Zwift 官方训练方法论、PMC开放获取研究（Peeters et al., PMC11502339, 2024）以及智能骑行台实操经验。本文件为 `cycling-power-coach` 的补充参考资料。

## 为什么室内训练越来越重要？

- **可控性**：不受交通、红绿灯、天气影响，功率输出完全可控
- **时间效率**：同样TSS，室内比室外节省30-40%时间（无滑行、无停车）
- **精准性**：ERG模式锁定目标功率，强迫执行训练计划
- **安全性**：高强度间歇无需担心车辆、路口
- **热适应训练**：可控高温环境，适合准备热地比赛

> 📊 PMC11502339调查（492名室内骑行者）：88.4%因天气原因转入室内，81.9%认为时间效率更高，70.9%用于维持基础体能。

## ERG模式 vs 坡度模式（Slope Mode）

### ERG模式（智能阻力控制）

**原理**：骑行台根据目标功率自动调节阻力，你无法"偷懒"也无法"狂踩"——踩踏频率变化，功率保持不变。

| 优点 | 缺点 |
|------|------|
| 精准执行功率目标 | 感觉"被机器控制"，不自然 |
| 无需换挡，专注踩踏 | 加速/减速无惯性，感觉"粘" |
| 适合间歇训练（自动切换功率） | 陡峭虚拟地形时体验差 |
| 新手友好 | 可能导致踩踏死点（cadence太低） |

**适用场景**：
- ✅ 结构化间歇训练（如4×15min甜区）
- ✅ FTP测试
- ✅ 恢复骑行（锁定Z1功率）
- ❌ 模拟真实地形骑行
- ❌ 需要频繁变速的训练

### 坡度模式（Slope/Simulation Mode）

**原理**：骑行台模拟真实路况——坡度大=阻力大，坡度小=阻力小，你需要自己换挡控制功率和踏频，和室外骑行一致。

| 优点 | 缺点 |
|------|------|
| 真实路感，自然变速 | 需要自觉维持目标功率 |
| 适合Zwift比赛/集团骑行 | 容易偷懒（功率不足） |
| 锻炼换挡技巧 | 需要更多注意力 |
| 惯性模拟更真实 | 间歇训练切换不如ERG方便 |

**适用场景**：
- ✅ Zwift 虚拟赛/集团骑行
- ✅ 模拟真实路线训练
- ✅ 恢复骑行（自然轻松）
- ❌ 精准功率控制训练（容易偏差）

### 混合策略

| 训练类型 | 推荐模式 | 理由 |
|---------|---------|------|
| FTP测试 | 阻力/坡度模式通常更适于自由配速的最大努力测试 | ERG预设目标可能限制真正极限 |
| 甜区间歇（4×15min） | ERG | 避免偷懒，精准执行 |
| VO₂max间歇 | ERG | 自动切换高低功率 |
| 长距离有氧（2h+） | 坡度 | 更自然，减少枯燥 |
| Zwift比赛 | 坡度 | 需要频繁变速和冲刺 |
| 恢复骑行 | ERG（低功率）或坡度 | 均可 |

> 💡 **ERG模式技巧**：踏频掉到<70rpm时，短暂停止踩踏让飞轮减速，然后以更高踏频重启——避免"踩不动"的死点。

## 室内 vs 室外 FTP 差异

### 室内与室外FTP不存在统一的高低方向

| 因素 | 室内 | 室外 | 影响 |
|------|------|------|------|
| 空气阻力与热环境 | 室内无真实前进风（需风扇散热） | 户外自然迎风 | 同样功率计瓦数仍是同样机械输出；体感会受散热与阻力控制方式影响 |
| 惯性 | 飞轮惯性小 | 下坡/滑行惯性大 | 室内更"累"但功率稳定 |
| 冷却 | 依赖风扇 | 迎面风自然冷却 | 室内过热→功率下降更快 |
| 路面 | 完全平稳 | 颠簸/风/坡度变化 | 室外需要更多神经肌肉适应 |
| 心理 | 枯燥，RPE更高 | 风景分散注意力 | 室内同样功率感觉更累 |

### FTP测试差异

**差异因人而异**：散热、姿势固定、阻力台惯性、测试协议、功率源与动机均会改变结果，不能默认室内FTP更高5–15%。

**原因**：
1. 室外需要应付风阻、交通、红绿灯——同样平均功率，实际训练质量更低
2. 室内缺乏自然迎面风，散热不足时同样瓦数可能**更吃力**；功率计测得的机械输出并不会因为室内无风阻而自动变小。

### 实践建议

| 场景 | 建议 |
|------|------|
| 主要在室内训练，偶尔室外 | 确认同一功率源和测试协议后，如长期存在差异可分别记录 |
| 室内外各半 | 先排查功率计一致性、散热及测试环境，勿机械套用高低比例 |
| 只用室内训练（冬季） | 用室内FTP，春季转室外时重新测试 |
| Zwift比赛 | 用室内FTP设定训练区间 |

> ⚠️ **重要**：同一功率在室内可能因散热、惯性和心理负担而感觉更累，也可能没有差异。**结合RPE、心率和身体症状共同判断训练强度**；尤其在停训后或FTP过期时，切勿只按固定瓦数强迫训练。

## 热管理与环境控制

### 室内骑行的热应激问题

**研究数据（PMC11502339）**：
- 78%的室内骑行者使用风扇降温
- 平均液体摄入：0.74±0.28 L/h（比室外多！）
- 96%试图控制室温

**为什么室内更容易过热？**
- 无迎面风冷却（速度为0）
- 身体产热无法通过空气对流散发
- 湿度累积（出汗但汗液不蒸发）

### 降温策略

| 方法 | 效果 | 实施建议 |
|------|------|---------|
| **风扇（必需）** | ★★★★★ | 至少1个强风风扇直吹上半身+头部 |
| **多个风扇** | ★★★★☆ | 1个吹头胸，1个吹腿部 |
| **冰袋/冷毛巾** | ★★★☆☆ | 间歇恢复时敷颈部 |
| **空调** | ★★★★☆ | 设定比室外低3-5°C |
| **勤换衣服** | ★★☆☆☆ | 湿透的骑行服隔热，休息时更换 |

**风扇摆放**：
```
骑行者正面
    ↑ 风扇1（头部+胸部）
    ↑ 风扇2（腿部，从侧面或下方）
```

> 💡 **核心温度监控**：如果骑行>90分钟，注意是否出现热衰竭症状（头晕、恶心、皮肤灼热但无汗）。室内骑行核心温度可比室外高1-2°C。

### 液体与电解质补充

| 骑行时长 | 液体摄入 | 电解质 |
|---------|---------|---------|
| <60分钟 | 视口渴、气温与出汗程度安排饮水；不强制每小时0.5L | 通常无需额外电解质 |
| 60-90分钟 | 结合个人出汗率、体感及场地热环境补水 | 高温/大量出汗时考虑电解质 |
| >90分钟 | 以出汗率、环境和胃肠耐受制定个体计划，避免大量过量饮水 | 根据出汗和食物来源考虑钠 |
| >2小时 | 长时段关注碳水和补水点，按个人出汗率调整 | 无统一强制钠/镁剂量 |

> ⚠️ 室内骑行出汗量可达1.5-2.0L/h（室外约0.5-1.0L/h）。**脱水>2%体重 → 功率下降5-10%**。

## Zwift训练计划

### Zwift内置训练计划评估

| 计划 | 时长 | 适合人群 | 评价 |
|------|------|---------|------|
| **FTP Builder** | 6-8周 | 初学者/重返训练 | 基础扎实，适合冬季 |
| **Build Me Up** | 8-12周 | 中级爱好者 | 综合提升，含爬坡和间歇 |
| **Crit Crusher** | 6周 | 绕圈赛/公路赛 | 高强度，适合春季 |
| **Gran Fondo** | 8周 | 长距离/世纪骑行 | 耐力为主，适合夏秋目标 |
| **Time Trial** | 8周 | 计时赛 | 甜区+阈值，强度高 |

### Zwift比赛策略

**功率管理**：
- 集团骑行：Draft节省30%功率，但要警惕"虚低"——出集团后功率需求骤增
- 爬坡：Zwift爬坡斜率固定，体重轻者优势大（W/kg关键）
- 终点冲刺：提前30秒加速，不要等到最后100米

**心理学**：
- Zwift数据实时可见 → 更容易"追数字"导致过度训练
- 虚拟对手制造压力 → 同样TSS，Zwift比赛RPE高1.0

### ERG模式在Zwift中的使用

- **训练**：开启ERG，专注完成功率目标
- **自由骑行/比赛**：关闭ERG，切换坡度模式
- **Zwift ERG bug**：有时功率锁定失效 → 手动关闭再开启ERG

## 室内训练专项：20分钟FTP测试

### 标准化流程

1. **热身**：15分钟Z2，最后3分钟含3×1分钟@Z4（激活）
2. **休息**：2分钟轻松踩踏
3. **测试**：在无疼痛、具备充分恢复且已适应室内骑行时，使用自主配速的20分钟最大可持续努力并记录平均功率；通常不建议用固定目标ERG限制极限发挥
4. **冷身**：10分钟Z1

**FTP = 20分钟平均功率 × 0.95**

### 室内FTP测试注意事项

| 问题 | 解决 |
|------|------|
| 起步太猛，后段崩盘 | 前5分钟保守（比目标低10-20W），后15分钟逐步加 |
| 过热导致后段掉功率 | 确保2+风扇直吹，提前冰敷颈部 |
| 无聊导致精神崩溃 | 听音乐或看视频（但不要让节奏干扰功率） |
| ERG模式"踩不动" | 踏频不要<70rpm，必要时短暂停止重启 |

> 💡 **Zwift FTP测试**：使用Zwift内置FTP测试（Ramp Test或20分钟测试），结果自动同步到TrainingPeaks/WKO+。

## RPE与疼痛的停止规则

室内训练必须同时使用功率、心率、RPE与局部症状，不可因ERG固定功率就忽略真实体感。停训数月、仍有腰背正中疼痛或手麻时，**不安排FTP最大努力测试或高负荷间歇**；如果踩踏再次诱发疼痛/麻木即结束。中断久后的首骑不应以原有FTP百分比给定强度，先用小功率、低时长与症状反馈试骑。

补液建议源于个体化评估而非固定每小时饮水/钠量。参考中国运动营养学会等2026共识： https://www.sciencedirect.com/science/article/pii/S2666337626001198
